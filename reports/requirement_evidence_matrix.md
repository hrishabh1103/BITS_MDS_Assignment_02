## 2. Academic Honesty & Negative Findings Disclosure

In compliance with academic evaluation standards, all negative experimental findings and domain limitations are openly disclosed:

1. **Citation Provenance vs. Factual Accuracy**:
   - The reported **100.0% Citation Precision** and **96.0% Citation Recall** represent *citation provenance consistency* (verifying that cited IDs exist within the retrieved context set and are not hallucinated identifiers).
   - They do **not** imply that the generative model is always factually or diagnostically correct.
2. **Q03 High-Voltage Retrieval Domain Mismatch**:
   - In Query Q03 (*"Vehicle battery goes completely dead overnight with alternator charging voltage testing normal during idle"*), dense semantic vector search retrieved high-voltage electric vehicle charging and interlock codes (`P0D17`, `P0D23`, `P0D46`) because the text "Battery Charger 14 V Power Supply" exhibited high vector similarity to the symptom.
   - The unguided RAG model initially accepted these records and instructed the user to inspect high-voltage battery cables for an ordinary 12V alternator drain.
   - **Resolution**: Backend guardrail engine now intercepts 12V ICE queries, detects retrieved EV DTCs, flags `ice_12v_battery_mismatch = True`, displays an alert banner, and injects strict prompt directives instructing standard fuse millivolt-drop testing.
3. **Q09 Airbag Squib Testing Safety Vulnerability**:
   - In Query Q09 (*Supplemental restraint system airbag light on after clock spring replacement*), the raw LLM output initially instructed technicians to "measure component resistance" across clock spring squib terminals.
   - In physical shop practice, the metering current of a standard digital multimeter can accidentally trigger pyrotechnic airbag deployment.
   - **Resolution**: Backend safety engine actively scans for SRS/airbag queries and injects mandatory directives prohibiting ohmmeter checks across squibs, warning that battery disconnect is not sufficient by itself, and mandating OEM dummy load simulators and factory service manuals.
4. **Dataset Characterization**:
   - The knowledge base contains **9,532 curated Diagnostic Trouble Code (DTC) entries**, documenting standardized SAE/ISO code definitions, verified probable causes, symptom presentations, and diagnostic checks.
   - It is **not** a collection of 9,532 real-world repair invoices or historical fleet repair histories.
